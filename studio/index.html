    03 / LEVE PARA O GITHUB

    Pronto para ser seu.

    Baixe um README em Markdown com seus textos e links. Não precisa de token ou instalação. As cores e animações do preview são exclusivas da opção SVG; este README usa a aparência do GitHub.

    1. Revise os textos, projetos e contatos de exemplo.
    2. Abra ou crie seu repositório público login/login.
    3. Copie o README.md para a raiz e salve no GitHub.

    Não inclui métricas ou calendários. Revise os textos de exemplo. Os textos são atualizados manualmente. O ZIP contém o README e as instruções.

    O site não escreve na sua conta. Rascunhos ficam neste navegador; links compartilhados incluem os textos e contatos. O provedor de hospedagem pode registrar acessos.
